## V1

- No memory leaks (I mostly use RAII in this project)
- Single DB, single user, multiple tables
  - DB is one file.
- A table row cannot exceed a page
- B+ tree
- Insert, select, delete execution
- Fixed row sizes, only support INT, FLOAT, TEXT (set length)
- Row sizes DO NOT EXCEED page size

## Not in V1

- What if a row exceeds a page size?
- PAX, if you can prove that it will be faster
- Testing harness might suffer partial writes
